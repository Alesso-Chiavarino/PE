# Presentación HTML del tercer parcial

Abrir `index.html` directamente en el navegador. No requiere instalación ni servidor.

## Controles

- Flechas izquierda y derecha: cambiar diapositiva.
- Barra espaciadora: avanzar.
- Botón **Guion**: mostrar u ocultar notas para la exposición.
- Botón **⛶**: pantalla completa.
- Botón **☰**: abrir el índice.

También puede imprimirse o guardarse como PDF desde el navegador.
